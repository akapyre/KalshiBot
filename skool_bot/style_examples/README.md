# Style examples

Put one of your real Skool posts in each file here, like `01.md`, `02.md`,
and so on. Paste the title on the first line and the post below it, exactly
as you wrote it, including emoji, spacing and sign-off.

Every post file here (not this README) is shown to the bot as an example of
your writing. 5-10 posts that cover a mix of post types (news, research
breakdown, poll, hot take) work best.
